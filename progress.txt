BUGS FOUND AND FIXED DURING THE QA LOOP (all caught by running the tests)
--------------------------------------------------------------------------------
1. sort=name:asc returned 422 - the Zod enum rejected the ":asc" suffix before
   resolveSort could whitelist it. Schema now validates only the shape.
2. X-RateLimit-* headers missing on the first request of a window - they were
   only set on the already-bucket-exists branch.
3. sort=bogus:asc silently sorted ascending - an unrecognised column kept the
   requested direction. It now falls back to (fallbackColumn, defaultDirection).
4. Role changes had no effect - authorisation trusted the `role` claim in the
   token. Roles are now read from the database on every request, which also makes
   account deletion revoke access immediately.
5. Test defect of my own: the "no cross-project leak" test posted both tasks to
   the same project. Test corrected.
6. Test expectation corrected: an injected ORDER BY string is now rejected at
   validation (422), which is stronger than the silent fallback asserted before.

Self-inflicted errors corrected during the build:
- `require()` used inside ES modules three times (would have crashed at runtime);
  replaced with static imports.
- Casts of node:sqlite rows failed type-check; routed through `as unknown as`.
- JSON body-parser errors would have surfaced as 500; now 400 / 413.
